# ArtMusic 🎵

> ⚠️ **Это личный проект, а не продукт.**  
> Плеер написан для себя и своих друзей, под конкретные задачи.  
> Здесь нет команды QA, код-ревью, семантического версионирования и SLA.  
> Возможны баги, странное поведение и внезапные поломки. Если что-то сломалось — это ожидаемо. Используй как есть.

---

## Что это

Простой веб-плеер для прослушивания музыки из Telegram-группы.  
Состоит из двух частей:

- **Фронтенд** — статический `index.html` (GitHub Pages).
- **Бэкенд** — Python (FastAPI + python-telegram-bot), который слушает группу и отдаёт треки фронту.

---

## Зачем

- Хочу слушать музыку, которую мы скидываем в общий Telegram-чат.
- Хочу открывать её с телефона, ноутбука, планшета — с любого устройства.
- Без подписок, рекламы, аккаунтов и «облачных библиотек».

---

## Возможности (то, что уже работает)

- Загрузка списка треков из загрузок на пк.
- Воспроизведение аудио.
- Прогресс-бар с перемоткой.
- Плейлист с поиском и удалением.
- Эквалайзер (5 полос) + пресеты.
- Регулировка громкости.
- Автоматический фон/свечение диска по обложке или названию трека.
- Режимы повтора и shuffle.
